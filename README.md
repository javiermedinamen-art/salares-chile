# Salares de Chile

Mapa interactivo de los salares y lagunas de Chile (inventario SNGM 2023), con ciencia y divulgación. Prototipo para la Fundación Salares.

## Sitio

Tras el deploy de GitHub Pages: `https://javiermedinamen-art.github.io/salares-chile/`

## Desarrollo local

```bash
npm install
npm run db:build   # genera public/data/ y copia MapLibre
npm start          # http://localhost:3000
```

También puedes abrir la carpeta `public/` con Live Server.

## Datos

- Contornos: Servicio Nacional de Geología y Minería (SNGM 2023).
- Proyectos, actividades y fotos del prototipo son **contenido de ejemplo**.
